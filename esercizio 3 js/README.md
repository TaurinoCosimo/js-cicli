# Esercizio
Chiedi all'utente di inserire il prezzo di un prodotto. Continua a chiedere prezzi e sommarli al totale finché l'utente non inserisce "0" per terminare. Stampa il totale della spesa.

## Ragionamento

- Chiedi all'utente di inserire il prezzo di un prodotto
- finche il prezzo e diverso da 0
    - somma il prezzo al totale
    - chiedi il prezzo di un prodotto
- stampa il totale
